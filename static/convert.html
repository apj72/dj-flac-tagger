DJ MetaManager

1 Choose folder & file The original file is never modified. Conversion uses ffmpeg (FLAC lossless, compression level 12). WAV and AIFF are both uncompressed — FLAC gives identical quality at ~50–60% the size. AIFF tags and artwork are copied to the output FLAC. Type a path and click Browse, or use Default / Choose folder (paths come from Settings → destination).

2 Output location Same folder writes a .flac next to the source. Destination sends output to your library folder from Settings (see the status line below).

3 Convert

Converts every .wav and .aiff under a root folder; optionally includes all subfolders. Original files are never deleted. AIFF tags and artwork are preserved in the output FLAC. Use Scan to count files before Run. Output mode is independent of single-file step 2.

4 Root folder Example: a Rekordbox or export tree. Scan finds all WAV and AIFF paths in sorted order so batch offset/limit is stable between runs.

Bulk output Next to each WAV: FLAC beside the source in the same tree. Mirror: recreate subfolders under Settings destination (avoids collisions across BPM folders). Flat: one folder for all outputs; filenames may use Slot - BPM - Artist - Title when the WAV name matches; tags embed from the same parse.

Mirrored mode keeps different subfolders from overwriting each other. Flat mode renames when the usual filename pattern matches. AIFF tags and artwork are always copied to the output FLAC.

Batching Large libraries: use a batch size and offset. Sorted order is the same every run. Skip-if-exists makes re-runs safe. Clear saved progress forgets the stored offset for this root. After a flat-folder run, open Bulk Fix on that folder. Turning off the limit runs everything in one go — use Scan first.
