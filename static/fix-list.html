DJ MetaManager

1 Import fix list Upload a CSV exported from Rekordbox Library Manager. The CSV identifies tracks with missing metadata (title, artist, BPM, key, artwork). DJ MetaManager reads the actual file tags and lets you fix them by searching Discogs, Apple Music, Bandcamp, SoundCloud, and Beatport.

2 Select & fix tracks Click a track in the list to see its details. Use "Fetch matches" to search online for the selected track, pick the best result from the dropdown or paste a URL, then "Apply" to write the metadata. Use "Fetch all matches" to search for every track in the list at once. Tracks marked with coloured badges are missing metadata.
