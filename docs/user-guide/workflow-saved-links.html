Saved Links

The Saved Links tab is a simple bookmark manager for music URLs you want to come back to later. Save links to Bandcamp pages, Discogs releases, SoundCloud tracks, Beatport listings, or any other URL while you are browsing and tagging — then revisit them when you are ready to buy, download, or process.

Adding links

Paste a URL into the input field and click Save (or press Enter). The link is stored immediately. You can optionally add a note or label alongside the URL to remind yourself why you saved it.

Managing links

Saved links are displayed in a list, most recent first. Each entry shows the URL (clickable to open in the browser) and any note you added. Click the × button to remove a link you no longer need.

Storage

Links are saved to saved_links.json on the server (under ~/Library/Application Support/DJ MetaManager/ for the packaged app, or next to app.py in development). They survive app rebuilds and browser changes.

Tip. Use Saved Links to collect URLs during a metadata session. When you find a Bandcamp or Discogs page that has tracks you want to purchase later, save the link here instead of relying on browser bookmarks that might get lost across profiles or machines.
